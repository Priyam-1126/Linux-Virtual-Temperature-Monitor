# Data Structures

This version will keep the data structures simple.

## TemperatureData

Stores the current sensor information.

Planned fields:
- temperature
- unit
- timestamp

## DeviceStatus

Stores the current device state.

Planned fields:
- device name
- status
- last reading

## Alert

Stores an alert generated by the system.

Planned fields:
- message
- temperature
- alert type
- timestamp

## C++ Approach

Classes and simple STL types will be used where they make the code easier to manage.
